# E3-007 — Diagnostic subset selector (n=100)

You are a background agent. Produces the locked deterministic list of 100 OCIDs the scaled diagnostic runs against. Same 100 records run on both primary and Claude (record-matched).

## Goal

Implement a deterministic selector that returns the 100 OCIDs whose `sha256(ocid)` hex digests sort lowest over the frozen 283-corpus. Commit the resulting list to `planning/diagnostic_subset.json` as a locked, reproducible artifact.

## Scope

### 1. Selector

`meshqu_runner/diagnostic/subset_selector.py`:

```python
import hashlib
import json
from pathlib import Path

def select_diagnostic_subset(corpus_ocids: list[str], n: int = 100) -> list[str]:
    """
    Returns n OCIDs whose sha256(ocid) hex digests sort lowest.
    Deterministic and reproducible: same input always yields same output.
    """
    keyed = [(hashlib.sha256(ocid.encode("utf-8")).hexdigest(), ocid) for ocid in corpus_ocids]
    keyed.sort(key=lambda t: t[0])
    return [ocid for _, ocid in keyed[:n]]
```

- Encoding: UTF-8 (deterministic). Hash: sha256 (deterministic). Sort: ascending lexicographic on the hex digest (deterministic).
- Returns a list of OCID strings, ordered as the sort produced them. The order is itself part of the locked artifact (downstream code can rely on it).

## Decision rules

- **Hash is sha256 of UTF-8 bytes.** Don't switch hash function; locked.
- **Selection key is the hex-digest string ascending.** Don't convert to int and sort numerically — string sort and numeric sort would differ on the leading zeros.
- **Output order matters.** Downstream consumers can rely on it. Don't shuffle.

## Out of scope

- The diagnostic runner itself (E3-008).
- Any subset > 100 (locked at 100 per the design; expansion is a tag amendment).
- Per-arm sub-selection (the same 100 run on both primary and Claude).

## Definition of done

- Branch `feat/e3-007-diagnostic-subset-selector`.

- PR body lists the rule, the first/last OCID, and the corpus total.

## Stop conditions

- Corpus size != 283 → STOP. The frozen archive has drifted from E1/E2's bound state; surface to Sam before locking a subset against a moving corpus.
- A duplicate OCID appears in the corpus → STOP. The selector assumes OCIDs are unique; surface.
- The sha256 of two OCIDs collide at the cut-off boundary (positions 100 and 101 share the same hash) → STOP. Surface; in practice this is astronomically unlikely (256-bit hash) but worth catching.
