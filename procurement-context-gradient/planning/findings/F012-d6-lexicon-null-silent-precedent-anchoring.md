# F012 — D6 lexicon-null + silent precedent anchoring (methodological + substantive)

**Status**: Discovered (dual disposition — methodological finding about the v1 lexicon AND substantive finding about agent prose behaviour; the experiment authors commit to BOTH readings rather than collapsing to one)
**Source experiment**: E2 (procurement-context-gradient) Phase 2 corpus `phase-2-20260522-101324-Z`
**Pre-registered prediction**: Dimension 6 (Precedent sensitivity) was operationalised against a lexicon of precedent-marker phrases — *"similar to"*, *"comparable to"*, *"as in record"*, *"the prior decision"*, *"the precedent suggests"*. The pre-registration did not name a numeric threshold; it predicted a non-zero mean hit rate at L3 / L4 (the rungs that contain precedent material).
**Authored**: 2026-05-22
**Restraint discipline**: This finding deliberately commits to BOTH the methodological framing (lexicon is too conservative) AND the substantive framing (silent anchoring is real behaviour) — single-reading suppression would falsely resolve the tension that the data itself preserves. The verdict-level data forces the both-and; pretending otherwise would be a restraint failure of the opposite kind to the one v1.1 §1.5 was written to prevent.

## Finding

The taxonomy v1 precedent-marker lexicon (*"similar to"*, *"comparable to"*, *"as in record"*, *"the prior decision"*, *"the precedent suggests"*) fired **zero times across all 1,415 reasoning texts** — at every level including L3 (where 107 records moved REVIEW → DENY at the precedent rung) and L4. Simultaneously, the verdict surface shows the agent demonstrably *responding* to precedents: the L2 → L3 transition is the experiment's headline verdict shift, and it is the rung at which precedent material first appears in the prompt. **The agent IS responding to precedents — verdicts move — but its prose does NOT name them.** This finding commits to two simultaneously-true framings: (i) the v1 lexicon is too conservative and the writeup should name it a v2 refinement target (embedding-similarity, paraphrase-aware coding, or hand-coded coding); (ii) silent precedent anchoring is a real behavioural mode — the agent does not externalise the influence of precedents in its prose, even when verdicts demonstrably depend on them.

## Interpretation

This is the finding where committing to a single reading would betray what the data actually shows. The corpus produces two simultaneously-true claims, and the writeup needs to honour both.

- **Reading (i) — methodological**: the v1 lexicon is conservative. *"Similar to"* and its cousins are explicit precedent-naming phrases; the agent's actual L3 reasoning rephrases precedent-derived reasoning in ways the bare lexicon cannot catch. A reading that fired *every* time the L3 reasoning contained "the publication delay is severe enough to constitute a clear timing failure" — language the agent only adopts at L3 — would catch what the v1 lexicon misses. v2 of the taxonomy should use embedding-similarity scoring between L3 reasoning and the precedent payload it received, OR hand-coded labelling by an analyst, OR both. The bare lexicon is the wrong instrument for this dimension; the writeup §7 (limitations) should name this as a measurement-floor limit explicitly.
- **Reading (ii) — substantive**: silent anchoring is a real behavioural mode in its own right. Even if v2 lexicon caught 80% of the influence-traces the agent emits, the *fact that the v1 lexicon caught 0%* is informative — the agent does not adopt the explicit "I am applying this prior decision to this record" framing that a human analyst would. Whether that is (a) a meta-cognitive limit (the agent cannot report which input shifted its weighting), (b) a stylistic property of GPT-class models (which tend to synthesise rather than cite), or (c) a learned property of legal-policy reasoning (where citation is a separate communicative act from analysis) — all three are plausible. The writeup should name this as a behavioural mode the experiment surfaced; it is not just a lexicon problem.

The both-and is what the verdict-level data forces. If verdicts had not moved at L3, Reading (i) would suffice (lexicon failed to detect a phenomenon that wasn't there). If verdicts had moved AND the lexicon had fired, Reading (i) would not be needed. The corpus produces the exact pattern that makes both readings load-bearing: verdicts move, lexicon fires zero times. Phase 3.3 should NOT collapse this to a single sentence in the writeup — it deserves a paragraph that names both readings and explains why both are simultaneously true.

## Implications for E3

- **Embedding-similarity precedent lexicon (v2)**: replace the bare-string-match v1 lexicon with embedding-cosine-similarity between L3 reasoning text and the L3 precedent payload that record received. Threshold for "precedent-influenced reasoning" can be calibrated against a small hand-coded golden set. This is the single most actionable methodological E3 ask coming out of Phase 3.
- **Hand-coded reasoning-text labels**: a small (e.g. 20-record) analyst pass that codes each L3 reasoning text against a 4-category rubric — *"explicitly names a precedent"*, *"paraphrases precedent-derived reasoning"*, *"reasons against generic intent (no precedent trace)"*, *"reasons against substrate detail only"* — would discipline both v1 and v2 lexicon claims.
- **A no-precedent L3 control**: an L3-substrate-only variant (substrate detail at L3 token length, but with no precedent payload) would isolate which token type causes the L2→L3 verdict shift. If the no-precedent L3 control still produces the shift, F008's claim that L3 receipts are the load-bearing input weakens. If it does not, F008 is sharpened.
- **Cross-model replication**: if GPT-class models exhibit silent synthesis but other model families (Claude, Gemini) emit explicit precedent citations, Reading (ii) narrows to a model-family property rather than a general LLM property.

## Anti-claims

- This finding does **not** establish that the agent is "hiding" or being deceptive about precedent influence. Silent anchoring is not concealment; chain-of-thought-style externalisation is a separate cognitive capability from being-influenced-by-a-prompt-input. The agent may simply lack the meta-cognitive surface to report which input shifted its weighting, and that is not the same as the agent choosing to obscure the input.
- This finding does **not** establish that precedents "caused" the L3 verdict shift in a counterfactual sense. The corpus shows the shift coincides with the rung that adds precedents; F012 documents that fact alongside the prose silence about precedents. A counterfactual claim ("the same agent given the same substrate without precedents would not have shifted") requires an L3-no-precedent control that E3 should run.
- This finding does **not** invalidate the v1 lexicon design as a methodological choice. v1 was a pre-data instrument chosen to be conservative and reproducible; the corpus shows it is too conservative for the precedent-sensitivity axis specifically. Other dimensions' lexicons (uncertainty markers, substrate-field names) DO fire and DO move across the ladder. v1's lexicon-based approach is not wrong in general; it is wrong for D6.
- This finding does **not** establish that precedent influence is unique to the L3 rung. The L4 rung also contains precedents (carried through from L3 in the level-batched cache). The lexicon fires zero times at L4 as well. The claim is about the dimension-level instrument failing, not about precedent-presence being a single-rung phenomenon.
- This finding does **not** conflict with F008's "L3 is the behavioural break" claim. F008 says verdicts shift at L3; F012 says the prose does not name what shifted them. Both are simultaneously true and together form the corpus's most interesting methodological data point.
